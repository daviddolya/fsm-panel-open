# Подготовка конфигов в рабочей копии

`config_cli` переносит подтверждённую запись userdata и синхронизацию autoexec
в отдельный каталог, созданный новой панелью. Оригинальная поставка и текущий
Steam не являются целями записи. Логические пути из старых настроек используются
в восстановленном плане; физические цели заданы внутри рабочей копии.

## Создание рабочего каталога

В интерфейсе откройте вкладку «Конфиги игры». Создайте или откройте ранее созданную
рабочую копию; затем импортируйте файл настроек и заполните поля на вкладке аккаунта
либо выберите шаблон на вкладке Autoexec. Кнопка применения доступна после предпросмотра.
Изменение любого входа сбрасывает его результат. Закрытие окна ждёт окончания записи;
приложение не прерывает замену дерева посередине. CLI ниже использует тот же адаптер.

```powershell
uv run python -m fsm_panel.config_cli workspace C:\FSM-Work\configs
```

Каталог должен отсутствовать. Команда создаёт маркер владения и структуру;
существующий произвольный каталог нельзя принять за рабочую копию. Маркер нельзя
переносить в установку Steam или оригинал. Исходные шаблоны храните отдельно.

## Конфиги аккаунта

Подготовьте копию settings JSON, видео-шаблон и machine-конфиг. Пример использует
синтетический Steam ID и логин. Время задаётся явно, чтобы предпросмотр воспроизводился:

```powershell
uv run python -m fsm_panel.config_cli account --workspace C:\FSM-Work\configs --settings C:\FSM-Inputs\settings.json --steam-id 76561197960265770 --login synthetic --video-source C:\FSM-Inputs\cs2_video.txt --machine-source C:\FSM-Inputs\cs2_machine_convars.vcfg --timestamp 1800000000
```

Ответ содержит fingerprint, число записей/удалений и группы старого алгоритма.
Содержимое конфигов и секреты в ответ не включаются. Настройки `STEAM_PATH`,
`DISABLE_STEAM_OVERLAY`, `NO_AVAST_MODE` должны присутствовать с правильными типами.
`--localconfig-copy` задаёт отдельный UTF-текст для восстановленной ветви замены;
его отсутствие и пустой файл — разные входы. `--force` меняет только сообщения
старого алгоритма и не разрешает перезапись произвольных файлов.

Для записи повторите **те же аргументы и timestamp**, добавив
`--apply --expect-fingerprint HASH_ИЗ_ПРЕДПРОСМОТРА`. Изменённый исходник или целевая
копия делают fingerprint устаревшим. Без `--apply` файловых изменений нет.
API дополнительно проверяет снимки непосредственно перед записью.

Цель: `steam/userdata/42` внутри рабочего каталога для ID из примера. Создаются
восстановленные общие VDF и игровые файлы; посторонние файлы сохраняются.
Предыдущая версия целого дерева остаётся в уникальной резервной копии.

## Autoexec

Разместите намеренно скопированный или синтетический каталог в
`C:\FSM-Work\configs\game\game\csgo\cfg`. Синхронизатор не создаёт отсутствующий cfg.
Имя старого файла задаётся явно: его глобальная инициализация ещё не восстановлена.

```powershell
uv run python -m fsm_panel.config_cli autoexec --workspace C:\FSM-Work\configs --source C:\FSM-Inputs\custom.cfg --config-file-name custom.cfg
```

Для применения также повторите команду с `--apply --expect-fingerprint HASH`.
При совпадающем полном тексте autoexec ничего не удаляется и время файла сохраняется.
При отличии в рабочей копии удаляются autoexec и указанный старый файл, затем
записывается новый autoexec; старая версия всего cfg остаётся в резервной копии.

## Кодировки, ошибки и восстановление

По умолчанию кодировка UTF-8. `--encoding` выбирает другую для старых текстовых
источников; восстановление mapped localconfig всё равно записывается UTF-8 согласно
бинарнику. Новые игровые файлы получают переводы строк Windows. Одинаковые файлы
autoexec и нетронутые файлы сохраняют точные байты.

Код возврата 0 означает завершённую команду, 2 — ошибку с постоянным кодом в JSON.
`config_preview_stale` требует нового предпросмотра. Ошибка записи может включать
`backup_path`, `staging_path`, `rollback_succeeded`; сохраните эти пути для отката.
Резервные копии автоматически не удаляются. Два переименования не дают гарантии
при потере питания; восстановление после аварийного завершения требует проверки
целевого каталога и сохранённой копии. Fingerprint — идентификатор предложения,
а не подпись или механизм авторизации.

Подробные адреса, порядок действий оригинала, пределы входа и осознанные отличия
приведены в [account-config.md](account-config.md). Это локальная подготовка конфигов;
принятие файлов реальными Steam/CS2 остаётся стендовой проверкой.
