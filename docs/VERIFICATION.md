## Упаковка и итоговый комплект

Сборка выполнена из чистого checkout `be01f5f`. Архив соответствующих исходников
включён отдельно. Более поздние изменения этого отчёта и инструкций не меняют код EXE.
Первая проверка обнаружила ошибочно выбранную упаковщиком стороннюю `icuuc.dll`:
Qt импортирует Windows-символы без суффикса, а выбранная DLL экспортировала `_78`.
Скрипт сборки теперь сверяет требуемые символы с Windows System32 и исключает
ошибочную копию из своего результата, не изменяя системные файлы. Повторный запуск
полного onedir-комплекта успешно проверен. Исключённые хеши записаны в manifest.

В `dist/FSMPanelOpen` находятся EXE, встроенный worker/Node, документация, контракты,
хеши всех файлов и перечни сторонних компонентов. `dist/FSMPanelOpen-source.zip`
содержит соответствующий чистый исходный checkout. `dist/FSMPanelOpen-research.zip`
объединяет эту поставку, исходники и настоящий итоговый отчёт на верхнем уровне;
верхний `VERIFICATION.md` уточняет более ранний снимок отчёта внутри сборки.

Сама проверка EXE выполнена на той же Windows 11 10.0.26200 машине. Очищенный PATH
и запуск вне репозитория доказывают конкретную работоспособность упаковки здесь,
а не прохождение ещё отсутствующего чистого стенда.

Независимый QA воспроизвёл 15 проблем и подтвердил их исправления. Среди них гонки
состояний и лицензии, двойная отправка через смену группы, восстановление неизвестного
исхода, отмена очистки процессов/GSI и ложный успех smoke при ошибке shutdown.
Подробные границы и отдельные checkpoint-результаты — в `docs/qa-review.md`.

## Воспроизведение

```powershell
uv sync --frozen --group dev
pnpm --dir worker install --frozen-lockfile
pnpm --dir worker typecheck
pnpm --dir worker test
pnpm --dir worker build
uv run ruff check src tests scripts
uv run ruff format --check src tests scripts
uv run mypy src
$env:QT_QPA_PLATFORM = 'offscreen'
# FSM_TEST_POSTGRES_URL должен указывать только на одноразовую тестовую БД.
uv run pytest -m 'not stand' --junitxml=test-results/python.xml --cov=fsm_panel.core --cov-branch --cov-report=json:test-results/core-coverage.json
uv run python scripts/check_branch_coverage.py test-results/core-coverage.json
uv run python scripts/verify_simulator.py --cycles 10 --output test-results/simulator-load.json
uv run python scripts/build_desktop.py --research-build
uv run python scripts/verify_desktop.py dist/FSMPanelOpen/FSMPanelOpen.exe --output test-results/packaged-smoke.json
uv run --no-project --python 3.11 research/verify_panel_constants.py '..\FSM_PANEL v.3.1.2\Panel.exe' --test
```

Без тестового PostgreSQL выбирайте `-m 'not stand and not postgres'` и указывайте
пропуск отдельно. CI имеет собственную службу PostgreSQL и отдельную Windows-сборку;
наличие workflow не означает, что удалённый CI прошёл. Этот отчёт фиксирует локальную
проверку; результаты последующих запусков доступны в
[GitHub Actions](https://github.com/daviddolya/fsm-panel-open/actions/workflows/checks.yml).
